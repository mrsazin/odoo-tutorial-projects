# Odoo Tutorial Modules

This repository contains multiple educational modules created while following the **official Odoo 18 developer tutorials**.  
Each module demonstrates a specific concept in backend or frontend Odoo development — from Python models to OWL JavaScript components.

---

## 📦 Included Modules

| Module | Description |
|--------|--------------|
| **awesome_clicker** | Demonstrates basic models, views, and actions in Odoo |
| **awesome_dashboard** | Shows how to create dashboard views and custom actions |
| **awesome_gallery** | Manages media gallery records with models and views |
| **awesome_kanban** | Demonstrates Kanban view customization and state handling |
| **awesome_owl** | Implements the [OWL JavaScript framework](https://www.odoo.com/documentation/18.0/developer/tutorials/discover_js_framework/) components |
| **estate** | A custom Real Estate example app for managing property listings |
| **website_airproof** | Integrates backend logic with Odoo Website templates |
