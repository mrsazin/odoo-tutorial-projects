# Odoo Tutorial Modules

This repository contains multiple example modules for learning Odoo 18 development.

## 📦 Included Modules

| Module | Description |
|--------|--------------|
| awesome_clicker | Demonstrates basic models and views |
| awesome_dashboard | Example of dashboards and actions |
| awesome_gallery | Manages media gallery records |
| awesome_kanban | Shows Kanban view customization |
| awesome_owl | Uses the OWL JavaScript framework |
| website_airproof | Demonstrates website and template integration |
